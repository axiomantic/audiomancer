# Golden Files

Expected outputs for testing analysis and conversion.

## Audio Analysis Golden Files
- kick_808_analysis.json - Expected analysis for kick_808.wav
- loop_125_rhythm.json - Expected rhythm analysis for loop_125bpm.wav

## Conversion Golden Files
- basic_beat.tidal - Expected Tidal output for basic_beat.mid
- basic_beat_pbind.scd - Expected SuperCollider output for basic_beat.mid

## Generating Golden Files

Golden files are generated by running analysis on known inputs
and manually verifying the outputs are correct.

### Process

1. Create or source a known-good input file
2. Run the analysis/conversion with verified correct implementation
3. Manually inspect the output to ensure correctness
4. Save the output as a golden file
5. Use in tests to detect regressions

### Example

```python
# Generate golden file for sample analysis
from audiomancer.analysis import analyze_sample
import json

result = analyze_sample("tests/fixtures/samples/kick_808.wav")

# Manually verify result is correct, then save
with open("tests/golden/kick_808_analysis.json", "w") as f:
    json.dump(result, f, indent=2)
```

### Using Golden Files in Tests

```python
def test_kick_analysis_regression(golden_dir):
    """Analysis should match known-good golden file."""
    from audiomancer.analysis import analyze_sample
    import json

    result = analyze_sample("tests/fixtures/samples/kick_808.wav")

    with open(golden_dir / "kick_808_analysis.json") as f:
        expected = json.load(f)

    assert result == expected
```

## Updating Golden Files

When intentionally changing behavior:

1. Review the changes in output
2. Verify they are correct and intentional
3. Update the golden file
4. Document why the change was made in git commit

# Audiomancer Configuration System

## Overview

Audiomancer uses a three-tier configuration system that merges settings from multiple sources:

1. **Builtin defaults** - Hardcoded values in `config.py`
2. **Global config** - `~/.config/audiomancer/config.yaml`
3. **Project config** - `.audiomancer.yaml` in project directory

Later tiers override earlier ones, allowing you to set personal defaults globally and override them per-project.

## Configuration Hierarchy

```
BUILTIN_DEFAULTS
    ↓
~/.config/audiomancer/config.yaml (optional)
    ↓ (deep merge, overrides)
.audiomancer.yaml (optional, auto-detected)
    ↓ (deep merge, overrides)
Final AudiomancerConfig instance
```

### Deep Merging

Configuration dictionaries are merged recursively. For example:

```python
# Builtin defaults
{
  "analysis": {
    "max_file_size_mb": 50,
    "embedding_dim": 128
  }
}

# Global config overrides max_file_size_mb only
{
  "analysis": {
    "max_file_size_mb": 100
  }
}

# Final merged config
{
  "analysis": {
    "max_file_size_mb": 100,  # from global
    "embedding_dim": 128      # from builtin
  }
}
```

## Builtin Defaults

Default values defined in `config.py` as `BUILTIN_DEFAULTS`:

```python
{
    "sources": {
        "samples": {"paths": []},
        "synths": {"paths": []}
    },
    "analysis": {
        "max_file_size_mb": 50,

        "embedding_dim": 128,
        "effnet_model": "discogs-effnet-bs64-1.pb"
    },
    "supercollider": {
        "sclang_path": None,  # auto-detect
        "boot_server": False,
        "timeout_seconds": 5.0
    },
    "storage": {
        "db_path": "~/.local/share/audiomancer/audiomancer.db",
        "embeddings_path": "~/.local/share/audiomancer/embeddings",
        "models_path": "~/.local/share/audiomancer/models"
    },
    "generation": {
        "default_bpm": 120.0,
        "default_bars": 4,
        "inference_timeout": 30.0
    },
    "logging": {
        "level": "WARNING",
        "file_level": "DEBUG",
        "log_dir": "~/.local/share/audiomancer/logs",
        "max_days": 7
    },
    "library": {
        "source_dir": "~/path/to/samples",  # Sample library source directory
        "project_root": "~/Development/my-music",
        "auto_analyze": True,
        "max_file_size_mb": 10,
        "copy_workers": 16
    }
}
```

## Global Config

File: `~/.config/audiomancer/config.yaml` (or `$XDG_CONFIG_HOME/audiomancer/config.yaml`)

This is your personal default configuration, shared across all projects.

### Example Global Config

```yaml
# Sample library management
library:
  source_dir: ~/Library/CloudStorage/GoogleDrive/My Drive/Samples
  auto_analyze: true
  max_file_size_mb: 10
  copy_workers: 16

# Sample source directories (for scanning)
sources:
  samples:
    paths:
      - ~/Music/Samples
      - ~/Downloads/Sample Packs
  synths:
    paths:
      - ~/synths
      - ~/.local/share/SuperCollider/synthdefs

# Audio analysis settings
analysis:
  max_file_size_mb: 50
  skip_patterns:
    - "*.asd"
    - "*.pkf"
    - "*.sfk"
    - ".DS_Store"
  embedding_dim: 128
  effnet_model: "discogs-effnet-bs64-1.pb"

# SuperCollider integration
supercollider:
  sclang_path: /Applications/SuperCollider.app/Contents/MacOS/sclang
  boot_server: false
  timeout_seconds: 5.0

# Storage locations
storage:
  db_path: ~/.local/share/audiomancer/audiomancer.db
  embeddings_path: ~/.local/share/audiomancer/embeddings
  models_path: ~/.local/share/audiomancer/models

# Pattern generation
generation:
  default_bpm: 130.0
  default_bars: 4
  inference_timeout: 30.0

# Logging
logging:
  level: WARNING
  file_level: DEBUG
  log_dir: ~/.local/share/audiomancer/logs
  max_days: 7
```

## Project Config

File: `.audiomancer.yaml` in project root directory

This is a project-specific configuration that overrides global settings. Auto-generated by `audiomancer init`.

### Example Project Config

```yaml
# Project: techno-live-set
# Created: 2025-12-30

# Override library paths for this project
library:
  project_root: ~/Development/techno-live-set
  source_dir: ~/Samples/Techno  # Different sample source

# Project-specific analysis settings
analysis:
  max_file_size_mb: 20  # Smaller limit for this project
```

### Minimal Project Config

You only need to specify what differs from your global config:

```yaml
library:
  project_root: ~/Development/my-music
```

Everything else inherits from global config and builtin defaults.

## Config Auto-Detection

The `load_config()` function automatically detects project context:

```python
from audiomancer.config import load_config

# Auto-detect project config by searching upward from cwd
config = load_config()

# Or specify explicit project path
config = load_config(project_path=Path("/path/to/project"))
```

### Search Algorithm

When `project_path` is not provided, `find_project_config()` searches upward:

1. Start from current working directory
2. Look for `.audiomancer.yaml`
3. If not found, check parent directory
4. Continue up to 10 levels or filesystem root
5. Return `None` if not found

Example directory tree:
```
/home/user/
├── Development/
│   └── my-music/           <- current directory: /home/user/Development/my-music/src
│       ├── .audiomancer.yaml  <- FOUND (2 levels up)
│       ├── samples/
│       ├── library/
│       └── src/
```

## MCP Server Auto-Detection

The MCP server (`audiomancer serve`) automatically detects project context:

1. When MCP server starts, it calls `load_config()` with no arguments
2. Config system searches upward for `.audiomancer.yaml`
3. If found, that project becomes the active context
4. All MCP tool operations use the detected project root

This means Claude Code automatically knows which project you're working in when you start chatting in a project directory.

### `.mcp.json` Marker File

The `audiomancer init` command also creates a `.mcp.json` file:

```json
{
  "mcpServers": {
    "audiomancer": {
      "command": "audiomancer",
      "args": ["serve"]
    }
  }
}
```

This tells Claude Code that this directory is an MCP-enabled project. When you open Claude Code in this directory, it can auto-discover and connect to the audiomancer server.

## Configuration Schema

### Library Config

```yaml
library:
  source_dir: Path         # Where sample packs live (local directory, network mount, etc.)
  project_root: Path       # Project directory (expects samples/ and library/ subdirs)
  auto_analyze: bool       # Auto-analyze samples when enabling packs (default: true)
  max_file_size_mb: int    # Skip files larger than this, 0=no limit (default: 10, range: 0-500)
  copy_workers: int        # Parallel copy workers (default: 16, range: 1-64)
```

Computed properties:
- `samples_dir` = `{project_root}/samples` (local cache)
- `library_dir` = `{project_root}/library` (active symlinks)

### Sources Config

```yaml
sources:
  samples:
    paths: List[Path]      # Directories to scan for audio samples
  synths:
    paths: List[Path]      # Directories for SuperCollider SynthDefs
```

### Analysis Config

```yaml
analysis:
  max_file_size_mb: int    # Skip files larger than this (default: 50, range: 1-500)
  skip_patterns: List[str] # Glob patterns to skip (e.g., "*.asd")
  embedding_dim: int       # Embedding vector dimension (default: 128, range: 64-512)
  effnet_model: str        # Essentia model filename (default: "discogs-effnet-bs64-1.pb")
```

### SuperCollider Config

```yaml
supercollider:
  sclang_path: Optional[Path]  # Path to sclang (auto-detect if null)
  boot_server: bool            # Boot scsynth on start (default: false)
  timeout_seconds: float       # Command timeout (default: 5.0, range: 1.0-30.0)
```

Auto-detection searches:
- `/usr/local/bin/sclang`
- `/usr/bin/sclang`
- `/Applications/SuperCollider.app/Contents/MacOS/sclang`

### Storage Config

```yaml
storage:
  db_path: Path           # SQLite database (default: ~/.local/share/audiomancer/audiomancer.db)
  embeddings_path: Path   # LanceDB vectors (default: ~/.local/share/audiomancer/embeddings)
  models_path: Path       # Pre-trained models (default: ~/.local/share/audiomancer/models)
```

### Generation Config

```yaml
generation:
  default_bpm: float          # Default tempo (default: 120.0, range: 60.0-200.0)
  default_bars: int           # Default pattern length (default: 4, range: 1-32)
  inference_timeout: float    # Generation timeout (default: 30.0, range: 5.0-120.0)
```

### Logging Config

```yaml
logging:
  level: str              # Console log level (default: WARNING, options: DEBUG|INFO|WARNING|ERROR|CRITICAL)
  file_level: str         # File log level (default: DEBUG)
  log_dir: Path           # Log directory (default: ~/.local/share/audiomancer/logs)
  max_days: int           # Log retention (default: 7, range: 1-30)
```

## Common Workflows

### Personal Setup

1. Install audiomancer
2. Create global config with your personal defaults:

```bash
mkdir -p ~/.config/audiomancer
cat > ~/.config/audiomancer/config.yaml <<EOF
library:
  source_dir: ~/path/to/your/samples

sources:
  samples:
    paths:
      - ~/Music/Samples
EOF
```

### Creating Projects

Use `audiomancer init` to create new projects:

```bash
cd ~/Development
audiomancer init --path my-techno-project
```

This creates `.audiomancer.yaml` with project-specific overrides.

### Multiple Projects

Each project can have different settings:

```
~/Development/
├── techno-project/
│   ├── .audiomancer.yaml  # source_dir: ~/Samples/Techno
│   └── samples/
├── ambient-project/
│   ├── .audiomancer.yaml  # source_dir: ~/Samples/Ambient
│   └── samples/
└── dnb-project/
    ├── .audiomancer.yaml  # source_dir: ~/Samples/DnB
    └── samples/
```

All share global config but override `library.source_dir` and `library.project_root`.

### Programmatic Usage

```python
from pathlib import Path
from audiomancer.config import load_config, save_config

# Load config (auto-detect or explicit)
config = load_config()
config = load_config(project_path=Path("~/my-project"))

# Modify config
config.analysis.max_file_size_mb = 100

# Save to global config
save_config(config)

# Save to project config
save_config(config, config_path=Path(".audiomancer.yaml"))

# Access nested config
print(config.library.samples_dir)  # Computed property
print(config.storage.db_path)
```

## Validation

All config values are validated using Pydantic:

- Path expansion (`~` and environment variables)
- Range constraints (min/max values)
- Enum validation (log levels, etc.)
- Type checking

Invalid configs raise `ConfigError` with details about the issue.

## Environment Variables

Config directories respect XDG Base Directory specification:

- `XDG_CONFIG_HOME` - config directory (default: `~/.config`)
- Config path: `$XDG_CONFIG_HOME/audiomancer/config.yaml`

## Migration from Older Versions

**BREAKING CHANGE**: The `load_config()` signature changed in this version.

**Old (pre-project-scaffolding)**:
```python
load_config()  # Always loaded from ~/.config/audiomancer/config.yaml
```

**New (current)**:
```python
load_config()                                 # Auto-detect project config
load_config(project_path=Path("/path"))      # Explicit project path
```

If you were using `load_config()` directly in code:
- No changes needed if using auto-detection
- If you need to force global-only config, pass `project_path=None` explicitly and the function will only load global config
